# forhuman.ca

The bilingual marketing site for **Human, an Education Collective** (人本・共學社).

## Architecture

Hybrid static site:

- **Marketing pages** (`public/*.html`) — hand-written HTML, CSS, and vanilla JS. No build step. Edit the files directly.
- **Blog** (`/writing/`) — Hugo. Drop markdown files into `blog/content/en/posts/` or `blog/content/zh-hant/posts/`, then run the build.
- **Bilingual routing** — EN at `/`, Traditional Chinese at `/zh-hant/`.

## Requirements

- **Hugo** `>= 0.163` — the blog generator. `brew install hugo` on macOS.
- **Python 3** — only for the local dev server. Any static file server works.

Everything else is browser-native.

## Commands

```bash
# Local development: serves public/ and rebuilds the blog on every markdown change
bash scripts/dev.sh        # visit http://localhost:4321

# Production build: rebuilds the blog, assembles everything in public/
bash scripts/build.sh
```

The production artifact is the entire `public/` directory. That's what gets deployed.

## Editing content

### Marketing pages

Just edit the HTML. No compile step. The design tokens live in `public/css/tokens.css` as CSS custom properties — reference them, don't hardcode values.

### Blog posts

1. Create a new file at `blog/content/en/posts/my-post.md`:
   ```markdown
   ---
   title: "Short, specific title"
   date: 2026-04-22
   summary: "One or two sentences for the homepage card preview."
   ---

   Body in markdown. No em dashes. Humanizer rules apply.
   ```
2. (Optional) Translate: create the Chinese mirror at `blog/content/zh-hant/posts/my-post.md` with the same filename and `lang: zh-Hant` in frontmatter.
3. Rebuild: `bash scripts/build.sh`.

### Design tokens

All colours, spacing, typography, and motion values live in `public/css/tokens.css`. They come from the Figma design system via `mcp-designer-for-human`.

If a Figma token changes, update the primitive value in `tokens.css`. Semantic and component-local tokens will inherit the change.

### UI/UX guidelines

Current site-level design guidance lives in `docs/ui-ux-guidelines.md`. In short: content renders before JavaScript, motion is an enhancement, mobile navigation includes the consult action, services stay scannable, and accessibility requirements apply to generated partials as well as hand-written pages.

## Deploy

Deployed as a Cloudflare **Worker** with static assets. `wrangler.toml` in the repo root tells `wrangler deploy` to upload `./public` at the edge.

In the Cloudflare dashboard (Settings → Build):

- **Build command:** `bash scripts/build.sh` — runs Hugo into `public/writing/`
- **Deploy command:** `npx wrangler deploy`
- **Root directory:** `/`
- **Environment variable:** `HUGO_VERSION=0.163.0`

Custom domain `forhuman.ca` is bound via the dashboard (Settings → Domains & Routes), not in `wrangler.toml`.

## Conventions

1. **Commits:** conventional format (`<type>(<scope>): <imperative>`). Atomic. No mixing content with code.
2. **No em dashes** in user-visible copy — they read as AI. Use commas, semicolons, or split sentences.
3. **Title case** for buttons, nav items, and section-title fragments. Sentence case for section titles that are complete sentences with a verb.
4. **Canadian English** spelling (colour, centre).
5. **ZH conventions:** 臺 not 台, 裡 not 裏, full-width punctuation, half-width space around English tokens in Chinese prose.
6. **All emails** render as `contact@forhuman.ca`.

## Language

The brand uses `Human,` with the trailing comma in every English context. The comma is a defining visual element, not a typo. In Chinese contexts, the brand is written as `人本` or `人本・共學社` — the comma does not transfer.
