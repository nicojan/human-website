# Human, website — design spec (sub-project A)

**Date:** 2026-04-22
**Scope:** The marketing website at `forhuman.ca` — hand-written static site plus a Hugo blog at `/writing/`.
**Out of scope (separate specs):** contact form backend (sub-project B, lives in `human-dashboard`), Matomo self-hosting (sub-project C, lives in a new `human-matomo` repo).

---

## 1. Goals

1. A marketing site the founder can edit by hand — no Node toolchain required to change headlines, copy, or structure.
2. A blog at `/writing/` that accepts markdown and rebuilds with a single command.
3. Bilingual (EN + Traditional Chinese) with clear URL routing and proper `lang` attribution.
4. Full visual parity with the Figma design and its tokens, implemented as layered CSS custom properties so future token changes propagate cleanly.
5. Lighthouse 100 accessibility on every page.
6. All user-visible copy passed through `mcp-humanizer` rules and written in the voice defined by `mcp-writer-for-human`.

## 2. Architecture decision

**Hand-written HTML/CSS/JS for marketing pages + Hugo for the blog.**

### Why hybrid (not Astro-only, not Hugo-only)

- Astro-only: loses the "edit by hand" benefit — every edit requires a Node build.
- Hugo-only: forces the founder to learn Hugo templating for every small marketing-page edit, even though those pages aren't content-driven.
- Hybrid: marketing pages are plain HTML. Hugo owns the blog, where its templating earns its keep through markdown authoring.

### Why Hugo (not Astro) for the blog

- Single binary, zero Node runtime. One command: `hugo`.
- Famously simple for content-only sites. Authoring is just dropping markdown files.
- Built-in multilingual support (`hugo.toml` `languages` block).
- Built-in `index.json` generation via output formats — perfect for the "latest 2 posts" module on the homepage.

## 4. Design tokens

All tokens live in `public/css/tokens.css` as CSS custom properties, layered so future changes cascade.

### Layer 1: primitives (colour, raw values)
Derived from `mcp-designer-for-human`'s `get_colour_palette`, `get_spacing`, `get_typography`.

- Colours: `--bark #322A22`, `--cream #FAF7F2`, `--cream-mid #F2EDE5`, `--white #FFFFFF`, `--ink #2B3A4E`, `--terracotta #B86F4A`, `--terracotta-light #F5E6DB`, `--sage #5B7254`, `--sage-deep #3D5236`, `--sage-light #E8EDE6`, `--ochre #C08B2E`, `--ochre-light #FBF3E0`, `--rose #B5454A`, `--rose-light #F5DEDE`, `--slate #3D6B80`, `--slate-light #DDE8EE`, `--ink-light #E0E4EA`, `--clay #C9906D`, `--neutral-200 #E5E1DB`, `--neutral-400 #B0A99E`, `--neutral-600 #6B655C`.
- Spacing: `--sp-xs 0.25rem` through `--sp-5xl 8rem` (13 steps, matches Figma `space/N`).
- Radius: `--radius-sm 6px`, `--radius-md 10px`, `--radius-lg 16px`, `--radius-full 9999px`.
- Breakpoints (documentation only, used in media queries): `--bp-sm 40rem`, `--bp-md 48rem`, `--bp-lg 64rem`, `--bp-xl 80rem`.
- Motion: `--ease-out cubic-bezier(0.16, 1, 0.3, 1)`, `--ease-in cubic-bezier(0.7, 0, 0.84, 0)`, `--ease-in-out cubic-bezier(0.45, 0, 0.55, 1)`, `--spring cubic-bezier(0.34, 1.56, 0.64, 1)`. Durations `--duration-instant 100ms`, `--duration-fast 200ms`, `--duration-normal 350ms`, `--duration-slow 500ms`.
- Elevation: `--shadow-xs` through `--shadow-xl`, all Bark-derived rgba.
- Max widths: `--max-width 72rem`, `--content-width 48rem`, `--sidebar-width 16rem`.

### Layer 2: semantic tokens
Alias primitives to roles.

- `--text-primary: var(--bark)`, `--text-secondary: var(--neutral-600)`, `--text-tertiary: var(--neutral-400)`, `--text-placeholder: var(--neutral-400)`, `--text-inverse: var(--white)`, `--text-brand: var(--terracotta)`, `--text-link: var(--ink)`.
- `--bg-canvas: var(--white)`, `--bg-warm: var(--cream)`, `--bg-surface: var(--cream-mid)`, `--bg-surface-hover: var(--neutral-200)`, `--bg-emphasis: var(--ink)`.
- `--border-default: var(--neutral-200)`, `--border-strong: var(--neutral-400)`, `--border-brand: var(--terracotta)`.
- `--action-primary: var(--terracotta)`, `--action-primary-hover: #A0603F`, `--action-secondary: var(--ink)`, `--action-secondary-hover: #1E2C3D`.
- `--focus-ring: var(--terracotta)`.
- Status tokens (`--status-success-fg/bg`, warning, error, info) map to sage/ochre/rose/slate pairs.

### Layer 3: component-local
Component CSS references semantic tokens only, never primitives.

Example:
```css
.button--primary {
  background: var(--action-primary);
  color: var(--text-inverse);
  border-radius: var(--radius-md);
}
```

### Typography tokens

- `--font-display: 'Literata', serif;` — EN display (note: Literata replaces Instrument Serif as the current brand display face).
- `--font-body: 'Atkinson Hyperlegible Next', 'Noto Sans TC', sans-serif;` — EN body with ZH fallback.
- `--font-body-zh: 'Noto Sans TC', sans-serif;` — ZH body explicit.
- `--font-display-zh: 'Noto Serif TC', serif;` — ZH display.
- `--font-mono: 'JetBrains Mono', monospace;`.

Type scale uses `clamp()` for fluid sizing on headings (H1-H3 and display). Body stays at 17px (1rem at 17px base) because mobile readability is already optimised.

Fonts loaded via Google Fonts with `<link rel="preconnect">` and `font-display: swap`. The exact URL:

## 8. Scroll animations

### Approach
`IntersectionObserver` adds a `.is-visible` class when an element enters the viewport. CSS transitions the element from its hidden to visible state.

### States
```css
[data-animate] {
  opacity: 0;
  transform: translateY(16px);
  transition:
    opacity var(--duration-slow) var(--ease-out),
    transform var(--duration-slow) var(--ease-out);
}
[data-animate].is-visible {
  opacity: 1;
  transform: translateY(0);
}
```

### Staggered children
Add `data-animate-stagger` to a parent with children having `data-animate`. JS applies `transition-delay: calc(var(--stagger-index) * 80ms)` up to a max of 5 items (from motion tokens: `stagger.max_items: 5`, `max_total_delay: 250ms` — we go 80ms × 5 = 400ms which is slightly looser, adjust if it feels slow).

### Elements to animate
- Hero headline + sub + CTA (staggered)
- Each principle block (as it scrolls into view)
- University logos (stagger across the grid, cap at 5)
- Outcome section title + logo grid
- Recent writing cards
- About page sections (each fades up as scrolled)
- Services cards (stagger)
- FAQ details (simple fade-in)
- Contact form entrance

### Reduced motion
`prefers-reduced-motion: reduce` short-circuits all of the above:
```css
@media (prefers-reduced-motion: reduce) {
  [data-animate] {
    opacity: 1;
    transform: none;
    transition: none;
  }
}
```

Also `site.js` pauses autoplay videos under reduced-motion and replaces their `poster` for still-image fallback.

## 9. Background colour rhythm (fix #7)

The previous build alternated `--bg-canvas` (White) and `--bg-warm` (Cream) only — user felt they were too similar.

New rhythm on the homepage (vertical):
1. Hero → `--bg-canvas` (White)
2. "Learning itself is the point" → `--bg-warm` (Cream)
3. Principles section → `--bg-canvas` (White)
4. Outcomes ("Where students go next") → `--bg-emphasis` (Ink, dark) — universities logos go on a dark inverse block, with `--text-inverse` text. Logos get `filter: brightness(0) invert(1) opacity(0.75)` on the dark background for uniform treatment.
5. Recent writing → `--bg-warm` (Cream)

## 12. Accessibility checklist (must pass before merge)

- Lighthouse a11y = 100 on every page (EN + ZH, all 8+ pages).
- Every image has `alt=` (descriptive) or `alt=""` (decorative).
- Every interactive element reachable via Tab, visible focus ring (`--focus-ring`, Terracotta).
- `lang` attribute on `<html>` (`en-CA` or `zh-Hant`).
- Inline language changes wrapped in `<span lang="zh-Hant">` or `<span lang="en">`.
- Videos: `aria-label` describing the content (since no captions).
- Form: every input labelled, required fields marked in text not just colour, errors use icon + text.
- Touch targets ≥ 44px.
- Color contrast AA minimum on every text/background pair (tokens enforce this by design, but verify).
- Skip-to-content link on every page.
- `prefers-reduced-motion` fully respected.

## 13. Copy rules applied throughout

- **No em dashes** (`—`). Replace with commas, periods, or semicolons.
- **No `x, not y`** contrastive construction (AI tell). Assert positively and stop.
- **Title case for buttons/nav/fragment-title sections.** Sentence case with terminal punctuation for section titles that are complete sentences with a verb.
- **Canadian English spelling** (colour, centre, programme for educational).
- **Serial comma:** yes.
- **Contractions welcome** in parent-facing copy (warmer, per writer MCP).
- **Avoid flagged words:** holistic, empower, leverage, stakeholder, synergy, 21st-century skills, best practices, paradigm, world-class, cutting-edge, best-in-class, unparalleled, facilitate, comprehensive, seamless.
- **ZH:** 臺 not 台, 裡 not 裏, full-width punctuation, half-width space around English tokens in Chinese prose.
- All emails rendered as `contact@forhuman.ca` (fix #8).
- Copyright year dynamic via `site.js`.

## 14. Risks and mitigations

| Risk | Mitigation |
|---|---|
| Hugo output path + baseURL mismatch breaks links | Test locally; Hugo's `RelPermalink` outputs include the `/writing/` prefix from baseURL |
| Shared nav/footer drifts between hand-written HTML and Hugo partials | Keep chrome HTML minimal. If drift appears, centralize via a build-time include (Hugo partial for the blog, direct paste for marketing) |
| Font flash on slow connections | `font-display: swap` + preconnect tags. Atkinson fallback to system sans is readable |
| `/writing/index.json` 404s before Hugo has built | `latest-posts.js` catches and silently hides the section |
| Autoplaying videos behave inconsistently across browsers | `playsinline muted autoplay loop` satisfies iOS Safari; JS pause on reduced-motion |
| ZH/EN fonts loading out of order causing FOUT | Preload Literata + Atkinson + Noto Serif TC (hero-critical fonts) in `<head>` |
